## Outcome

在 P1/P2 已验证的文本主链和可靠 Run 上，闭合截图 OCR 隐私生命周期、四种交通 Evidence、天气与风险来源的受控/snapshot/live Provider 分层证据。

```text
截图/文本 → OCR/Parser → TripBrief 确认 → Provider Adapters
→ EvidenceSnapshot/Receipt → Audit/Advice → Repair → 完整 postcheck
```

## Scope

- PNG/JPEG/WebP 截图输入、OCR 版本/文本框/置信度和终态清理回执；
- 驾车、步行、公交、骑行统一 Provider adapter 与字段级失败语义；
- 天气与风险来源进入 EvidenceSnapshot，确定性事实与建议性判断分离；
- 受控 fixture、固定 snapshot 与 live Provider receipt 分层记录，不互相替代；
- 继续固定北京、上海、杭州、单城市、2～5 人、2～5 天。
- 复用 migration `022`～`024` 与现有公共 HTTP API/schema，不新增 migration 或公共字段；
- live Provider 最小矩阵固定为三城各四种路线、一次天气和一次风险查询，最多 18 次调用；只允许既有免费额度/配额，增量付费预算为 0。

## Non-goals

- 不扩城、不跨城，不新增 Agent、消息队列、Kubernetes、GraphRAG 或模型微调；
- 不启动 Builder、Planner、RAG、LoRA、Yjs 或 OR-Tools admission；
- 不修改 frozen blind/oracle，不把 fixture/snapshot 晋级为 live/public/user evidence；
- 不公网部署、不真人招募、不合并 `main`。
