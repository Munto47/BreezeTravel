# BreezeTravel 双模式与横链画布实施计划

产品合同见 [PROJECT_CHARTER](../product/PROJECT_CHARTER.md)，当前进度见 [CURRENT_GOAL](CURRENT_GOAL.md)。实施基线为长攻略修复检查点 `a43b1a8`；旧 G07 与旧 R0 只保留为历史。

## 串行切片

1. **渐进生成与停止**：扩展 202 与 SSE 公开投影、累计脱敏快照、资源级游标、事件流优先／轮询降级、取消竞争与迟到 worker 防写回。
2. **两视图横链画布**：接回现有横链／导航供体，以当前 Hook、真实 `RouteMap`、编辑和预览面板为权威；共享横滚、固定日期、弧线、手机列表模式。
3. **拖动、预演与导出**：图片或把手拖动即时预览、相邻卡片让位，松开一次写入；键盘保留确认；真实几何客户端预演；完整无底图 PNG。
4. **协同运行时与换肤**：精确挂载旧链所需 API，收口公开投影与假成功，恢复房间、Yjs、四节点 AI、明确触发驾车排线及本地／Compose 生命周期。
5. **单向转换**：读取当前成员最新成功保存路线，白名单规范成文字，经 v3 重新理解核验，保持房间不变。
6. **集成验收**：先完成离线回归、固定数据闭环、生产构建和四视口验证；达到自动化 R0 候选后立即交付所有者三份文字攻略体验。真实 Qwen／高德与真实协同 AI／驾车属于 R1 验证，不阻塞 R0 体验。

同一时间只集成一个切片。子 Agent 只复核与诊断，产品代码由主任务串行写入。每个切片先有用户可见闭环，再补最小必要测试；一个问题最多两种不同修复策略。

## 接口增量

- `GET /api/v3/trip-understandings/{id}/result` 的 202 增加 `phase`、`event_cursor`、`progress` 和可选脱敏 `snapshot`。
- 现有 SSE `progress` 增加相同阶段、计数和累计快照；终态仍为 `result_available`。
- `POST /api/v3/trip-understandings/{id}/cancel` 要求 `Idempotency-Key`，返回 `STOPPED_WITH_DRAFT / STOPPED_EMPTY / ALREADY_FINISHED`。
- `POST /api/v3/trip-understandings/from-collaboration` 请求仅 `{room_id}`，要求登录与幂等键，返回现有 202 accepted view。
- 追加 migration 为理解任务、资源和修订增加 `CANCELLED`，不新增公开 job ID 或导出表。

## 分级交付

| 等级 | 交付含义 | 最小结果 |
|---|---|---|
| R0 | 所有者本地体验 | 40 条无危险输出且至少 28 条自动符合；3/3 攻略返回卡片或诚实部分结果，至少两份经少量编辑可用，一份完成卡片→编辑→路线需更新→手动更新→PNG；协同固定闭环、停止、重连和预演可操作 |
| R1 | 封闭受控试用 | 至少 36/40；真实 Qwen＋高德行程查一次、真实协同 AI＋驾车一次；双用户同步、重开和转入行程查成功 |
| R2 | 新版候选 | 40/40 精确通过，完整响应式、无障碍、Provider 和候选矩阵通过 |

R0/R1 是有效成果但不称 G07 通过。普通样式和边缘识别可记录降级；地点身份、隐私、删除、自动算路、未知冒充成功与推测路线失败时必须关闭能力或诚实受限。

## 必测范围

- 现有 v3、认证、地图、住宿、检查后端、分享和隐私安全不得回退。所有者明确移除独立优先检查页面后，5 条仅适用该页面的浏览器场景保留为 RETIRED_CHECKS_PAGE，不计入通过数量；保留读写并发、失败恢复、内部信息不泄漏等验证。
- SSE：首次、续订、多行／坏帧、重复倒退事件、资源隔离、旧任务迟到、轮询单飞降级。
- 取消：有／无快照、幂等重放、完成竞争、取消 worker 迟到提交。
- 横链：单／双／多卡、空日、响应式回环折行、同日／跨日移动、取消零写、确认一次、键盘移动、路线失效和手动更新。
- 预演零网络；PNG 包含视口外全部日期和待确认／过期／受限标记，ETag 变化不下载。
- 协同：登录、创建／加入、双客户端 Yjs、三类 AI 进度、显式排线、真实驾车或诚实不可用、五分钟令牌刷新。
- 转换：非成员、无／空／坏保存路线、幂等、字段白名单、新行程归属、旧房间零修改。
- 1440、1280、390、360px 与前端生产构建。

## 停止点

达到 R0 后立即交付所有者真人体验，不等待完整候选。生产部署、公开发布、`main` 合并、招募 H1、付费或新外部数据权限均不在本目标授权内。
