## 接口增量

- `GET /api/v3/trip-understandings/{id}/result` 的 202 增加 `phase`、`event_cursor`、`progress` 和可选脱敏 `snapshot`。
- 现有 SSE `progress` 增加相同阶段、计数和累计快照；终态仍为 `result_available`。
- `POST /api/v3/trip-understandings/{id}/cancel` 要求 `Idempotency-Key`，返回 `STOPPED_WITH_DRAFT / STOPPED_EMPTY / ALREADY_FINISHED`。
- `POST /api/v3/trip-understandings/from-collaboration` 请求仅 `{room_id}`，要求登录与幂等键，返回现有 202 accepted view。
- 追加 migration 为理解任务、资源和修订增加 `CANCELLED`，不新增公开 job ID 或导出表。
