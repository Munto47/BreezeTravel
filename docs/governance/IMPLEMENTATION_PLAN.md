# 五城识别与餐宿实施计划
1. 固定develop基线、真实失败样本和逐项分类，统一入口及当前回归。
2. 局部语义恢复、分支/父子/漏项核对，单项地点故障有界恢复。
3. 可扩展五城地点/商圈/住宿区资料，统一城市核验。
4. 每日餐饮建议→采纳→刷新→撤销→手动更新路线。
5. 逐夜酒店、跨城住宿段、门店核验和请求预算。
6. 同版真实评估、桌面手机端到端、本地检查点及失败清单。

验收以[产品定义](../product/PROJECT_CHARTER.md)与[评测说明](../testing/FIVE_CITY_EVALUATION.md)为准，不将固定回放当效果。
首批50实际攻略，逐步200五城（开发100/验证50/留出50）加30普通城市/跨城；同原文家族隔离，复杂样本三次保留全部失败。
采集每城约150实体/10商圈/5住宿区及3–5商户为起点，不作为运行时配额。
隔离工作树实现，识别/城市/住宿并行负责范围，主任务处理餐饮/前端/API/文档并串行集成。每切片本地checkpoint，实际状态写CURRENT_GOAL。无发布/推送/main合并，首次服务使用独立数据库。
