# 双入口文档说明

本目录保存双入口产品的当前状态、执行协议和日期化证据。

## 当前状态

- `capability-status.md`：目标能力的当前状态入口。状态变更必须有对应 evidence，不能由历史报告自动推断。

## 协议与清单

- `comprehensive-dual-entry-testset-2026-08-21.md`：完整测试集和门禁说明。
- `m1-human-calibration-protocol.md`：真人校准协议。
- `legacy-migration-inventory.md`：旧模型与迁移清单。

## 日期报告

其余带日期文件记录某次本地、Provider、恢复或门禁运行。它们是不可改写的历史证据，不代表当前分支仍满足同一结论；当前声明必须同时绑定代码提交、配置、数据和最新 release manifest。
