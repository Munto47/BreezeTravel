# ADR-011：知识、第三方 Provider 与用户记忆边界

- 状态：Accepted
- 日期：2026-08-27
- Program：`TC-VNEXT-2026`
- 延续：ADR-006 的风险Provider准入原则

## 背景

典型游览时长、适合时段、夜景、季节和热门程度能提高建议质量，但这些内容会过期，也可能受版权、平台条款和商业使用限制。无授权抓取小红书不能构成稳定壁垒。用户偏好能改善低频旅行体验，但原始攻略、截图和聊天长期留存会扩大隐私风险。

## 决策

新增建议性 `KnowledgeClaim`：

- canonical place；
- claim type和条件；
- source tier、URL和短证据；
- observed/effective/expires；
- license/storage status；
- reviewer和版本。

硬事实只来自官方、政府、运营方或已准入Provider。正规媒体、授权创作者和用户内容只用于建议。RAG不能决定POI、路线或HARD Finding。

小红书在没有官方读取权限和明确许可前状态为BLOCKED，不抓取、不持久化。

用户记忆：

- 默认关闭；
- 只保存步行、出发、餐饮、酒店和强度等结构化偏好；
- 可查看、修改、清空和删除；
- 产品记忆consent与训练/评测consent分离；
- 原始攻略、截图和聊天默认不进入长期记忆。

SourceDocument留存不等同用户记忆：G01即提供加密存储、30天上限、行程/账号删除、匿名24小时清理和可回读删除回执。到期删除原文和可还原quote，只保留不可逆hash、结构化结果、版本与删除回执；训练、评测、公共知识或内容飞轮使用必须另行同意。

高德完整响应和路线geometry按条款短期使用；生产持久化和商业展示前取得明确许可。

## 后果

- 知识有来源、时效和撤回路径。
- 内容飞轮来自用户纠正与授权反馈，不依赖无授权抓取。
- 需要Provider Admission、过期任务、删除回读和consent测试。
- 未解决许可可以阻断生产，但不伪装成代码失败。

## 不采用

- 任意网页全文向量化：许可、过期和事实权威不清。
- GraphRAG：当前三城建议问题不需要复杂图运行时。
- 默认长期记忆原文：隐私成本大于收益。
- 用社交热度作硬事实：无法证明当前真实状态。

## 验证

Knowledge Admission Gate、Consent & Share Gate、删除回读、越权、过期、来源级别和RAG消融。
