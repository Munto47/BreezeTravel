# 五城效果评测
首批50实际平台攻略或授权原文，逐步200五城（开发100/验证50/留出50）加30普通城市/跨城回归。
来源分platform_generated、human_authored_authorized、developer_constructed；构造不能冒充平台或真人。原文及改写同family不能跨组；留出失败用于修复后转回归，另取新留出，不建签名封存平台。
标注主线/备选/否定/日序/再访/分馆分店；身份以官方/地图核对，生成模型不能为唯一裁判。

指标按城市报告分子/分母和全部失败：
- 主线召回≥95%、精确≥99%、日序≥98%；遗漏/误增/错角色单列。
- 地点身份及区域/分店正确，服务失败分开；不只比较名称。
- 最终正确可见主站/原文明示主站≥95%，隐藏项保留分母；留出整篇无需主要修正≥90%。
- 适用日餐饮候选≥90%，已有午餐不重复；住宿每晚边界/跨城段正确，缺失通勤如实。
- 样本错城/错分店/菜品变地点/虚构为零；权限、删除、幂等、撤销、并发、零编辑自动算路必须保持。
- 关键复杂样本重复3次不取最好；分层P50/P95、HTTP请求、token及可知费用。

未运行NOT_RUN，样本不足INSUFFICIENT_DATA。固定回放只证明实现，真实模型/地图和真人体验分别报告。
scripts.run_product_checks读取product_test_manifest.json，本地与CI共用。真实语料位于忽略目录，公开报告仅脱敏摘要。沿用现有模型/地图授权，不新增费用与追踪。
