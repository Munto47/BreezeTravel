# 前端重构对照

本文件是实施索引，产品行为以 PROJECT_CHARTER、顺序以 IMPLEMENTATION_PLAN、完成情况以 CURRENT_GOAL 为准。依据项目所有者提供的《行程查_前端重构设计与开发计划》及本次明确要求，对实际代码逐项核对后实施。

| 现有有效能力／缺口 | 新位置与行为 | 接口依据 |
|---|---|---|
| 匿名真实输入、固定回放 | 首页文本输入；示例预填、确认整理，编辑示例转真实输入 | v3 创建 FULL／DEMO |
| 每日卡片与高德地图 | 当天纵向活动／交通行，日期靠近内容，桌面双栏、手机切换 | result、map-renders/latest |
| 地点详情、候选查询 | 左栏上下文面板；先选择地图候选，再确认使用 | place-candidates、PLACE_CONFIRM |
| 时间、停留、移动、删除 | 统一编辑面板，未修改或取消不写入，脏表单离开确认 | commands + ETag + 幂等 |
| 检查与建议采纳 | 活动旁说明，统一前后差异预览，采纳原子执行，撤销可恢复 | checks、changes/preview、changes/adopt、UNDO |
| 原均匀顺延 | 改为逐站计算，空档吸收延误，保护预约与缺失路线 | ACTIVITY_TIMES_APPLY |
| 路线过期 | 旧路线不冒充当前；依赖旧交通的问题待复检，用户主动更新 | map-renders、basis_status |
| 原文只能删除，不能核对 | 所有者按需查看／复制与查看原文中的地点名称；不恢复已删或到期数据 | source GET／DELETE |
| 取消与备选未呈现 | 当天末尾折叠；日期不明单列，不生成执行路线 | supplementary GET |
| 住宿和有来源建议 | 当天辅助区域与地点详情保留，不扩大能力 | stay-suggestions、knowledge_suggestions |
| 已有账号领取，缺少真实账号列表 | 独立“我的行程”，服务器分页、期限、重开和删除 | me/trips、result、DELETE resource |
| 登录／资料／记忆删除 | 保存后返回原行程；账号设置保留低频能力 | 现有账号及 privacy 接口 |

视觉使用近白背景、深色正文、低饱和绿；正文 15–16px，辅助 13–14px，44px 操作目标，以分隔、留白和对齐组织。无可靠图片来源时不用装饰性假照片。地图失败只影响空间视图，不能阻断修改。

自然语言修改、顺路比较与知识问答未来统一接入变更预览，不另建行程状态或直接修改数据库。未实现能力不显示无效按钮。原房间、旧历史、冻结的多 Agent／OCR 入口不进入新导航。
