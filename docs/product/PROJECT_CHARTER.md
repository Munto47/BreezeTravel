# BreezeTravel 当前产品定义

2026-09-07用户批准五城识别与餐宿方案。本文是当前规格，历次反馈原件见[归档](../governance/archive/pre-five-city-20260907/INDEX.md)。

## 产品和交付
行程查为默认匿名文字入口；协同规划需登录，保留房间、同步、AI问答与明确触发的驾车排线。保存路线可单向转入行程查重新核验，不反向覆盖房间。
本轮为本地北上广深杭完整识别、餐饮、住宿；其他城市保留行政核验后基础搜索。不扩展OCR/截图、生产部署、公开招募、训练或新服务。

## 识别与失败
首页无城市、人数、日期、酒店或账号必填表单；缺失值为可编辑软假设。继续最多14天/160项边界，超限不截断后冒充完整。
区分主线、备选、说明、取消、路过，保留分支、父子关系和再访。菜品、品牌、眺望对象不变成已选门店。模型理解语义，服务端核验引用、身份与路线。地点库只辅助别名和漏项核对。
正确片段保存，错误片段有限修复；只展示确认地点主卡片，未处理/未匹配保持计数和可展开补全，不隐去分母。

## 页面和编辑
主视图为卡片/地图。保持紧凑蛇形回环、两行外侧连线、逻辑序号及真实交通摘要；线形不表达地理距离。手机列表与键盘操作保留。
图片/把手拖动，取消零写入、松手一次；Enter提起/放下、方向调整、Escape取消、Delete防误删。地点卡旁选择确认，共用写锁。卡片不展示编辑时间/停留，历史字段兼容保留。
编辑和撤销创建新版本，保存/刷新/响应丢失/并发冲突可恢复。POI照片失败使用九类授权装饰图，每类十图稳定分配，不宣称实拍。
地图只用服务端真实结果，首次异步准备、编辑后手动更新。步行≤30分钟用步行，否则真实公交；失败不猜测线或分钟。
保留真实SSE进度、停止、恢复、取消与迟到结果隔离。2.5秒提示不驱动进度，阅读暂停/减少动画有效；PNG导出覆盖所有日期并标明过期/缺失。

## 餐饮
每适用日一组中途用餐建议，优先明确午餐空位，否则游览中段，无时刻不猜12点。已明确午餐保留且可替换，不重复插入。
显示商圈和最多3家核验饭店，前后站真实路线比较；缺路段仅称附近候选。建议与原文分开，采纳才写入并使地图过期。
首次异步准备不阻塞卡片；编辑后建议失效，由用户更新，旧候选不可采纳。

## 住宿
每晚D末站→酒店→D+1首站；首日早晨、末日取行李仅原文明示才算。同城连续住宿默认一家，跨城分段，已有明确酒店保留。
热门区与短通勤区共同召回门店。集团/品牌/门店分层核验，华住优先；平均单程差≤10分钟优先华住，否则同时展示方便连锁和华住备选。
每段最多12召回、6精算、3展示，96次路线预算并发4，缺失通勤如实标注。无预算/日期/房态不承诺便宜可订有房；偏好可选。

## 技术、安全、验收
复用Next.js/React、FastAPI/Pydantic单体、v3URL/命令与worker，PostgreSQL唯一业务事实源，Redis缓存。追加兼容字段/migration，不重写旧记录。
秘密仅HttpOnly cookie，ETag不透明；日志、公共API及DOM不泄漏原文、秘密、内部诊断。权限、删除、并发、幂等、撤销和零编辑自动算路不可降低。
五城主站召回≥95%、精确≥99%、日序≥98%、正确可见覆盖≥95%、留出整篇无需主要修正≥90%，适用日餐饮候选覆盖≥90%。隐藏项计入分母，样本零错误不等于总体零风险。
固定回放、真实模型/地图、平台生成输入与真人体验分开。当前仅本地交付，服务器更新另行决定。
