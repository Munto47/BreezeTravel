# 城市资料与采集
按城市行政编码分区，版本化资料和可重建索引；无固定配额。现900条作为待复核种子，不因写了核验日期就视为每个别名有证据。
实体区分景点/分馆/入口/交通/商圈/住宿区/具体商户；关系区分别名、位于、内部、附近和品牌。允许同名歧义，不把附近当同义。
记录来源URL、采集和核验日期、适用范围、核验状态。坏记录隔离，发布失败保留上一有效包，其他城市继续服务。
AI平台提供真实生成输入，小红书提供俗称和偏好线索，身份由官方与地图核验。品牌与门店分开，名称包含不能证明集团归属。
动态开放、预约、价格、房态单独带适用日期，未知/过期不作保证；原文和账号内容不公开，仅按授权保留必要片段。缓存遵守来源限制，服务错误不缓存为无地点。
采集起点每城150实体/10商圈/5住宿区及各3–5商户，按高频失败扩充，不全国分页穷举；披露实际覆盖和待核对清单。
