# BreezeTravel 文档索引

本文只说明文档位置和效力，不定义新的产品目标。

## 当前权威入口

- `../README.md`：项目入口、运行方式与公开能力边界。
- `../AGENTS.md`：仓库级开发指导。
- `BreezeTravel_双入口可验证行程产品与架构重构最终方案_2026-08-20.md`：当前产品与架构基线。
- `dual-entry/capability-status.md`：新产品能力的当前证据状态。
- `governance/PROJECT_CHARTER_DRAFT.md`：待共同定稿的产品愿景、阶段目标与开发约束草案；当前不取代 Final 2.0。
- `ARCHITECTURE.md`、`RELIABILITY.md`、`SECURITY.md`：当前工程约束。
- `EVALUATION.md`、`EVIDENCE.md`、`REPRODUCE.md`：评测口径、证据和复现方式。

## 目录用途

- `adr/`：仍生效的架构决策记录。
- `dual-entry/`：双入口开发协议、阶段报告和证据记录；日期报告不自动成为当前状态。
- `research/`：产品与市场研究输入。
- `runbooks/`：部署和操作手册；使用前需要现场复核。
- `governance/`：产品目标、开发授权和完成定义；带 `DRAFT` 的文件不具备权威效力。
- `interview-review/`：面试复习资料，不参与产品门禁。
- `archive/`：已被取代的方案和历史 Review，不得用于驱动当前开发。

当文档间结论冲突时，不通过“选择更有利的一份”解决；应先修正当前权威基线或新增 ADR。
