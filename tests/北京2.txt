# 北京3天家庭游（老少友好，不暴走）
>住宿建议：住**前门/崇文门**，地铁方便，去各大景点都近。所有景点**必须实名预约，带身份证**，故宫周一闭馆（节假日除外）。

## Day1｜中轴线：天安门—故宫—景山（皇城核心）
1. 上午：**天安门广场**（提前预约），看纪念碑，拍照打卡。
2. 上午‑中午：**故宫博物院**（午门进，神武门出），走中轴线：太和殿→乾清宫→御花园，体力够再加珍宝馆。游玩3‑4小时，自带水和小零食。
3. 下午：**景山公园**（2元门票），登万春亭俯瞰故宫全景，绝佳拍照点。
4. 晚上：什刹海/烟袋斜街散步，吃铜锅涮肉，感受胡同夜景。

🍜吃饭：故宫附近吃烤鸭/炸酱面，避开景区路边高价小吃。

## Day2｜长城一日（家庭优先慕田峪，人少好走）
>慕田峪比八达岭人流少，更适合一家人出行
1. 早上：去**慕田峪长城**
- 省力方案：**索道上、滑道下**，走6‑14号敌楼精华段，不用全程爬完，老人小孩友好。
- 山上物价高，提前备好水、零食。
2. 下午返回市区，回酒店短暂休整。
3. 傍晚：**奥林匹克公园**，看鸟巢、水立方夜景，只在外围拍照即可，不用进馆内。

🍜晚餐：老北京铜锅涮肉。

>备选：如果家人体力很差，不想跑长城，可以把这天换成**国家博物馆+雍和宫**。

## Day3｜皇家园林+天坛，轻松收尾，方便返程
1. 上午：**颐和园**（北宫门进），苏州街→佛香阁→长廊→昆明湖→十七孔桥。想省力可以坐昆明湖游船，少走路。
2. 中午：颐和园附近吃炸酱面。
3. 下午：**天坛公园（一定要买联票）**，逛祈年殿、回音壁、圜丘坛，古树很多，环境舒服。
4. 傍晚：**前门大街+大栅栏**，逛老字号，买稻香村伴手礼，吃小吃，之后直接去车站/机场返程。

# ⚠️家庭出行重要提醒
1. **预约是重中之重**
- 故宫：提前7天20点放票，无现场票，很容易抢完。
- 天安门广场：提前7天预约，大小都要身份证。
- 天坛、颐和园现场可买票，但节假日建议线上买好。
2. 鞋子一定要穿舒服运动鞋，北京旅游走路非常多；备好水杯、防晒、帽子。
3. 长城不要相信路边“一日游小广告”，优先官方直通车/正规交通。
4. 不要买错稻香村：认准**三禾稻香村**，才是北京本地老牌子。
